    About PromptLab
    
            
    PromptLab tests candidate prompts by running them through a configured Performer and evaluating the resulting answers against the task and rubric.
    
            
    
              
    
                
    Gemini Optimizer
    
                
    Generates initial prompt candidates and creates improved child prompts from evaluation feedback.
    
              
    
              
    
                
    Gemini Performer
    
                
    Runs each selected candidate against a shared sample and returns the response that is evaluated.
    
              
    
              
    
                
    Groq Judge
    
                
    Evaluates the Performer response against the confirmed TaskIntent and task-specific rubric. The backend validates criterion weights and calculates the normalized reward.
    
              
    
              
    
                
    Stage A — Feedback improvement
    
                
    Uses a parent candidate’s own Judge feedback, with session insights as additional context, to generate a new child prompt while preserving intent.
    
              
    
              
    
                
    Stage B — UCB selection
    
                
    Selects which existing candidates to evaluate next using their reward history and an exploration term. UCB selects candidates; it does not rewrite prompts.
    
              
    
              
    
                
    Final evaluation and report
    
                
    Re-evaluates finalists and the original prompt baseline, ranks candidates using final scores, and creates a PDF from session data.
    
              
    
            
    
            
    
              
    Session and provider notes
    
              
      
                
    • Session data is held in server memory and is lost when the server restarts.
      • 
                
    • With mock mode enabled, local development responses are marked as mock and do not represent live provider results.
      • 
                
    • Live mode uses Gemini for optimization and performance, and Groq for judging.
      • 
                
    • Judge scores are estimates and do not guarantee an objectively best prompt.
